# Optional: the honest ON-DEVICE layer.
#
# A real local OCR pass on CPU — no GPU, no cloud, no network once installed.
# Verified on Python 3.14 / Windows with rapidocr 3.10 and onnxruntime 1.31
# (see docs/offline-proof.md for what was actually run and what it read).
#
# Pick ONE:

# (a) PP-OCR via ONNX Runtime — best accuracy per MB, no torch, no GPU.
#     rapidocr ships with its Chinese/English detection + recognition models
#     inside the wheel, so the default path needs no download at run time.
rapidocr>=3.10
onnxruntime>=1.31

# For Hindi / Marathi pages, set OCR_LANG=devanagari in .env. RapidOCR then
# fetches the PP-OCRv5 mobile Devanagari recognizer once (~7 MB) and caches it
# beside the package. Latin names and digits stay on the default model, which
# reads them better; the two models are a swap, not a blend.

# (b) PaddleOCR — heavier, needs paddlepaddle.
# paddleocr>=2.7
# paddlepaddle>=2.6

# (c) Tesseract — needs the system binary installed separately, plus Pillow.

# pillow>=10
