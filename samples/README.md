# Samples

These files are **fixtures**. They are hand-written for demos and tests so that
anyone reviewing this project can click through the whole flow without a camera,
an API key, or a real shop's book.

They are **not** field evidence and must never be shown as such.

- `sample_ledger.txt` — one clean page: twelve lines, three scripts, both
  directions. Balances: Ramesh Patil owes ₹140, Imran Shaikh ₹505, Ganesh
  Kulkarni ₹300, and so on.
- `hard_page.txt` — the same notion of a page after a bad photograph: smudges,
  a struck-through line, a misread digit (`Z-oO`), one line with no name.
  It exists to show what the product does when it *cannot* read something.

Real pages carry real customer names and amounts. If you photograph one to test
with, keep it out of git — `field-photos/` and `samples/real/` are already
ignored for that reason. Blur or change the names before the photo goes
anywhere public, and ask the shop before you photograph their book.
